# Архитектура системы

## Назначение

Информационная система предназначена для автоматизации учета посещаемости и успеваемости студентов ФГБОУ ВО «МГУТУ им. К.Г. Разумовского (ПКУ)». Система реализована как веб-приложение и как настольное Windows-приложение. Обе версии используют одну базу PostgreSQL, поэтому изменения, внесенные в одном интерфейсе, доступны в другом.

## Роли пользователей

- Администратор управляет пользователями, группами, дисциплинами и назначением преподавателей.
- Преподаватель ведет электронные журналы по назначенным дисциплинам, отмечает посещаемость и выставляет оценки.
- Студент просматривает личную посещаемость, текущие и итоговые оценки.
- Все пользователи просматривают расписание в соответствии со своей ролью.

## Основные сущности базы данных

- `Profile` — роль и контактные данные пользователя.
- `StudyGroup` — учебная группа и направление подготовки.
- `StudentCard` — карточка студента, номер зачетной книжки и связь с группой.
- `Subject` — учебная дисциплина.
- `Course` — электронный журнал дисциплины для конкретной группы, преподавателя, семестра и учебного года.
- `Lesson` — занятие в рамках электронного журнала.
- `AttendanceRecord` — отметка посещаемости студента на занятии.
- `Grade` — оценка студента по занятию, контрольной, экзамену или итоговой аттестации.
- `ScheduleEntry` — недельное расписание пары: день недели, время, аудитория, группа, дисциплина и преподаватель.

## Разграничение доступа

Доступ к страницам закрыт авторизацией Django. Дополнительно проверяется роль пользователя:

- преподаватель видит только свои журналы;
- студент видит только данные своей группы и собственные результаты;
- администратор имеет доступ к административной панели и сводным данным.

Роли синхронизируются с группами и правами Django. При смене роли пользователя система автоматически назначает нужную группу прав.

## Используемые технологии

- Python 3.11+;
- Django;
- PostgreSQL;
- pgAdmin для администрирования базы данных;
- HTML, CSS для адаптивного пользовательского интерфейса.
- C# WPF для настольного Windows-клиента;
- Npgsql для подключения C#-приложения к PostgreSQL.

## Настольный клиент

ПК-клиент расположен в каталоге `desktop-csharp/`. Он реализует расширенный интерфейс для демонстрации дипломного проекта:

- авторизация через существующие учетные записи Django;
- администрирование пользователей, ролей, групп, дисциплин, журналов и расписания;
- ведение электронного журнала преподавателя;
- выставление итоговых оценок;
- зачетная книжка студента;
- аналитика посещаемости, распределения оценок и учебных рисков;
- поиск по таблицам и экспорт отчетов в CSV.
- встроенные PNG-ассеты для экрана входа и аватаров ролей;
- панель преподавателя с расписанием текущего дня;
- массовые операции в журнале занятия;
- автоматическая рекомендация итоговой оценки на основе среднего балла и посещаемости.

## Типовой сценарий работы

1. Администратор создает пользователей, группу, дисциплину и электронный журнал.
2. Преподаватель открывает журнал дисциплины и добавляет занятие.
3. Преподаватель отмечает посещаемость студентов и выставляет оценки.
4. Администратор составляет недельное расписание для групп и преподавателей.
5. Студент входит в личный кабинет, просматривает расписание, зачетную книжку и результаты обучения.
